# YouTube Downloader

![Flutter](https://img.shields.io/badge/Flutter-Framework-blue)
![Dart](https://img.shields.io/badge/Dart-Language-blue)
![Platform](https://img.shields.io/badge/Platform-Android-green)
![License](https://img.shields.io/badge/License-MIT-green)

A modern **Flutter mobile application** that allows users to download videos from YouTube directly to their device.

The application provides a simple and intuitive interface where users can paste a YouTube link and download the video easily without ads. The downloaded videos are stored locally on the device for offline viewing.

This project demonstrates Flutter development skills including UI design, media downloading, and file handling.

---

# Features

- Download YouTube videos using a URL
- Simple and clean user interface
- Save videos directly to device storage
- Fast download process
- No ads
- Lightweight application

---

# Tech Stack

This project was built using the following technologies:

- **Flutter** – Cross-platform mobile development framework  
- **Dart** – Programming language used in Flutter

# Installation

### 1 Clone the repository

```bash
git clone https://github.com/Faress213/Youtube-Downloader.git
```

### 2 Navigate to the project folder

```bash
cd Youtube-Downloader
```

### 3 Get dependencies

```bash
flutter pub get
```

### 4 Run the application

```bash
flutter run
```

---

# How to Use

1. Open the application.
2. Copy the YouTube video URL.
3. Paste the link into the input field.
4. Tap the **Download** button.
5. The video will be saved to your device.
